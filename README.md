# second-state Homebrew tap

```bash
brew install --cask second-state/tap/vibebuddy
```

| Cask | What it is |
| --- | --- |
| `vibebuddy` | [VibeBuddy](https://github.com/second-state/vibebuddy), the desk companion that announces what your AI coding agents are doing. Apple Silicon, macOS 14 or later. |

The app updates itself; `brew upgrade` is not needed. The cask follows new releases on its own: `.github/workflows/update-vibebuddy.yml` checks once an hour.
